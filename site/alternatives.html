CYBERDOG

Cyberdog compared with other SSH and SFTP clients

Cyberdog is a free, open-source desktop app that puts an SFTP file explorer, a terminal and a server health dashboard in one window, on macOS, Windows and Linux. These pages explain, feature by feature and without hiding where the others are stronger, how it compares with the tools you may use today.

What Cyberdog is built for

  • One window for files, terminal and server health, over a single SSH connection with no agent on the server.
  • More than SFTP: FTP/FTPS, S3-compatible storage, Azure, WebDAV, SMB, Dropbox, OneDrive and Google Drive.
  • Bastions with a route test, teams with roles and history, ten secret-vault connectors.
  • Free and open source (MIT). Passwords stay in your system keychain. No telemetry.
