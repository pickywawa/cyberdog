05 / GOOD TO KNOW

Avant de vous connecter.

Est-ce que Cyberdog est gratuit ?

Les outils locaux de Cyberdog restent gratuits et le cœur est disponible sous licence MIT. Les extensions Premium sont propriétaires : espace personnel, partage en équipe, historique et coffres de secrets.

Faut-il installer quelque chose sur le serveur ?

Aucun agent Cyberdog n’est nécessaire. L’explorateur utilise SFTP et le terminal utilise SSH. Les vues avancées s’appuient sur les outils disponibles : systemd, Docker, OpenSSL ou Certbot, selon les fonctions et les permissions du compte.

Mes connexions passent-elles par un service cloud ?

Non. L’application se connecte directement depuis votre ordinateur à vos serveurs. Les serveurs locaux restent sur votre ordinateur. Si vous activez le Premium, les configurations partagées sont hébergées sur Supabase et les licences vérifiées via Lemon Squeezy. Les mots de passe SSH des coffres ne sont pas envoyés à Supabase. La vérification et le téléchargement des mises à jour contactent GitHub.

Les certificats SSL sont-ils surveillés en permanence ?

La vue SSL analyse les fichiers de certificats accessibles sur le serveur et les actualise tant que cette vue est ouverte. Elle ne surveille pas les serveurs lorsque l’application est fermée. Le renouvellement est proposé pour les certificats gérés par Certbot.

Comment importer mes serveurs ou signaler un problème ?

Le menu d’import accepte les configurations Cyberdog en ZIP, les favoris Cyberduck, le XML FileZilla et l’INI WinSCP. Pour une question ou un bug, ouvrez une issue sur GitHub sans inclure de mots de passe ni de données confidentielles.
