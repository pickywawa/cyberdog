04 / BASTIONS

Atteignez les serveurs
privés. En confiance.

Choisissez « Via un bastion » dans la fiche d’un serveur. Cyberdog ouvre SSH vers le bastion, un canal vers la cible, puis une seconde session SSH chiffrée de bout en bout depuis votre poste. Rien à installer sur le bastion.

  • Un bastion réutilisable par plusieurs serveurs, avec ses propres identifiants.
  • Test du trajet avant d’enregistrer : bastion, canal, authentification de la cible, SFTP.
  • Empreintes du bastion et de la cible vérifiées : une empreinte modifiée bloque la connexion.
  • Fichiers, terminal et diagnostics suivent le même trajet. Codes MFA demandés à la connexion.

08 / GOOD TO KNOW

Avant de vous connecter.

Est-ce que Cyberdog est gratuit ?

Les outils locaux de Cyberdog restent gratuits et le cœur est disponible sous licence MIT. Cela inclut l’espace personnel, le partage en équipe, l’historique et les coffres de secrets.

Cyberdog gère-t-il autre chose que SFTP ?

Oui : FTP et FTPS, le stockage compatible S3 (AWS, Google Cloud Storage, Backblaze B2, Wasabi, DigitalOcean Spaces, Scaleway), Azure Blob et Azure Files, WebDAV, SMB (macOS et Windows), Dropbox, OneDrive et Google Drive. Le terminal, la santé du serveur, Docker et les logs concernent les serveurs SSH.

Faut-il installer quelque chose sur le serveur ?

Aucun agent Cyberdog n’est nécessaire. L’explorateur utilise SFTP et le terminal utilise SSH. Les vues avancées s’appuient sur les outils disponibles : systemd, Docker, OpenSSL ou Certbot, selon les fonctions et les permissions du compte.

Mes connexions passent-elles par un service cloud ?

Non. L’application se connecte directement depuis votre ordinateur à vos serveurs. Les serveurs locaux restent sur votre ordinateur. Si vous créez un compte, les configurations partagées sont hébergées sur Supabase. Les mots de passe SSH des coffres ne sont pas envoyés à Supabase. La vérification et le téléchargement des mises à jour contactent GitHub.

Puis-je tout faire au clavier ?

Oui. Flèches pour se déplacer, Entrée pour ouvrir, ⌘↑ pour le dossier parent, F2 pour renommer, ⌘C / ⌘X / ⌘V pour copier ou déplacer entre serveurs, ⌘L pour saisir un chemin, ⌘1…9 pour les onglets et Ctrl+` pour le terminal. ⌘/ affiche la liste complète. Sous Windows et Linux, ⌘ devient Ctrl.

Les certificats SSL sont-ils surveillés en permanence ?

La vue SSL analyse les fichiers de certificats accessibles sur le serveur et les actualise tant que cette vue est ouverte. Elle ne surveille pas les serveurs lorsque l’application est fermée. Le renouvellement est proposé pour les certificats gérés par Certbot.

Comment importer mes serveurs ou signaler un problème ?

Le menu d’import accepte les configurations Cyberdog en ZIP, les favoris Cyberduck, le XML FileZilla et l’INI WinSCP. Pour une question ou un bug, ouvrez une issue sur GitHub sans inclure de mots de passe ni de données confidentielles.
