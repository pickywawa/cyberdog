Confidentialité

Ce site présente Cyberdog, un projet de pickywawa. Dernière mise à jour : 24 octobre 2026.

Ce site web

Le site n’utilise aucun outil d’analyse d’audience, formulaire ou cookie publicitaire. Le choix de langue est conservé uniquement dans le stockage local de votre navigateur. La galerie et les animations fonctionnent localement.

Le site est hébergé par GitHub Pages. Il interroge l’API publique de GitHub pour afficher la dernière version et les liens de téléchargement. Ces requêtes et l’hébergement impliquent la transmission de données techniques, notamment votre adresse IP, à GitHub. Consultez la politique de confidentialité de GitHub.

L’application

Cyberdog se connecte directement de votre ordinateur à vos serveurs via SSH et SFTP. Sa configuration est stockée dans le dossier local configuré dans l’application. Les recherches de mises à jour et leurs téléchargements contactent GitHub. Ce site n’a aucun accès à vos serveurs ou à la configuration de l’application.
