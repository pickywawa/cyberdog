Confidentialité

Ce site présente Cyberdog, un projet de pickywawa. Dernière mise à jour : 27 octobre 2026.

Ce site web

Le site n’utilise aucun outil d’analyse d’audience, formulaire ou cookie publicitaire. Le choix de langue est conservé uniquement dans le stockage local de votre navigateur. La galerie et les animations fonctionnent localement.

Le site est hébergé par GitHub Pages. Il interroge l’API publique de GitHub pour afficher la dernière version et les liens de téléchargement. Ces requêtes et l’hébergement impliquent la transmission de données techniques, notamment votre adresse IP, à GitHub. Consultez la politique de confidentialité de GitHub.

L’application

Cyberdog se connecte directement de votre ordinateur à vos serveurs via SSH et SFTP. Sa configuration est stockée dans le dossier local configuré dans l’application. Les recherches de mises à jour et leurs téléchargements contactent GitHub. Ce site n’a aucun accès à vos serveurs ou à la configuration de l’application.

Premium facultatif

Le Premium utilise Lemon Squeezy pour les licences et Supabase pour les espaces personnels et équipes. Ces services traitent l’email d’achat, les informations de licence et les configurations que vous choisissez de partager (serveurs, groupes, actions, chemins et historique). Les droits sont vérifiés côté serveur. Les mots de passe SSH restent locaux ; les secrets lus dans les coffres ne sont pas envoyés à Supabase. Les connecteurs contactent directement le fournisseur choisi et restent configurés localement. Le paiement, lorsqu’il sera disponible, sera hébergé par Lemon Squeezy : Cyberdog ne reçoit pas vos données bancaires.

Contact et licence

Le cœur public est sous licence MIT ; les extensions Premium sont propriétaires. Pour une question, utilisez les issues GitHub. Ce canal est public : n’y publiez aucun secret ni information confidentielle.

Privacy

This website presents Cyberdog, a project by pickywawa. Last updated: October 27, 2026.

This website

This site has no analytics tools, forms or advertising cookies. Your language preference is stored only in your browser’s local storage. The gallery and animations run locally.

The site is hosted on GitHub Pages and requests GitHub’s public API to display the latest release and download links. Hosting and these requests transmit technical data, including your IP address, to GitHub. See GitHub’s privacy statement.

The application

Cyberdog connects directly from your computer to your servers using SSH and SFTP. Configuration is stored in the local directory selected in the app. Update checks and downloads contact GitHub. This website has no access to your servers or application configuration.

Optional Premium

Premium uses Lemon Squeezy for licensing and Supabase for personal spaces and teams. These services process purchase email, license information and configurations you choose to share (servers, groups, actions, paths and history). Permissions are checked on the server. SSH passwords remain local; secrets read from vaults are not sent to Supabase. Connectors contact your chosen provider directly and remain locally configured. Once available, payments will be hosted by Lemon Squeezy: Cyberdog does not receive bank card data.
